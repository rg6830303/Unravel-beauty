# Unravel Beauty — Mobile Design Preview

[Open the live preview](https://rg6830303.github.io/Unravel-beauty/)

The homepage is the exact standalone HTML export of the cave-and-glass mobile design. It includes the supplied SVG logo, a stationary cave background, translucent panels, drifting mist and leaves, product-card tilt, searchable navigation, and an interactive demonstration bag.

## Publishing

GitHub Pages serves the repository root from main. No build step is required. index.html is the complete standalone preview, with embedded imagery and logo; prototype/index.html mirrors that same file. Icon and positioning libraries load from pinned CDN URLs, so internet access is required.

## Preview scope

This is a mobile homepage design for review, displayed in a contained mobile frame on larger screens. The bag is local demonstration state; checkout, payments, authentication, and Supabase are not connected. Collection and informational links open the existing Unravel website. Reviewers can share the live URL and return comments or annotated screenshots.

The previous JavaScript, styles, design audits, and generated mockups remain in the repository for future implementation, but the new homepage does not load the old storefront scripts or styles.
